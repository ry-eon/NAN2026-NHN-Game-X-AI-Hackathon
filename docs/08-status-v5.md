# 08. v5 현황 — 「마지막 성벽」 3D 농성전 (2026-07-27 기준)

> 세션 재개용 스냅샷 + 해커톤 제출 문서(게임 소개서·AI 활용 기술 문서)의 원재료.
> 상세 작업 내역·프롬프트·반려 기록은 `docs/logs/2026-07-25.md` 등 디렉팅 로그 참조.

## 1. 지금 게임이 뭔가

- **나는 성주다**: 플레이어는 성주 캐릭터 하나로 3D 성 내부를 직접 걸어다닌다.
- LoL식 고정 부감 카메라 + 우클릭 이동 + 휠 줌. (WASD 아님 — 사용자 확정)
- 준비 단계에서 성을 둘러보고, Space로 침공 개시 → 괴수들이 **전면 광역**으로 몰려온다 (일자 레인 아님).
- 난이도는 1라운드 단일 고정.
- 프로젝트 논지는 유지: **"생성이 아니라 보증"** — 결정론 sim을 봇이 검증하고 통과분만 출고.
- v1~v4(2D 그리드 디펜스, Phaser)는 **폐기가 아니라 보존**: `legacy-2d` 브랜치 (63+ 테스트, 봇 3종, 파이프라인 포함). main은 3D 재출발 (`15526aa`부터).

## 2. 코드 구조 (v5)

```

client/src3d/main.ts   # Three.js 부트스트랩·카메라·입력(부대 선택/명령)·FX·보간 렌더 루프
client/src3d/environment.ts  # 성·지형·하늘·소품 (절차 생성 + CC0 에셋)
client/src3d/models.ts # 절차 캐릭터(풀아머 기사)·공성 병기(대포/발리스타)·화염 FX
```

### sim 핵심 (siege/sim/world.ts)
- 30Hz 고정 틱, 연속 XZ 좌표, mulberry32 시드 RNG. 입력은 커맨드형(`moveTo`/`unitMove`/`startAssault`) = 그대로 리플레이 포맷.
- **M2b 전투 (2026-07-26 구현)**: 아군 4종 `UNIT_KINDS`(궁수/발리스타/대포/영웅) — 사거리·쿨다운·대포만 AoE.
  정지 시에만 사격(히트스캔, 투사체는 연출). 괴수는 지상(h<1) 아군 접전 우선 > 성벽 공격.
  부대 명령은 id 정렬 + 결정론 대형 오프셋, 성주와 같은 `Mover` 규칙(BFS·계단·2층·벽 슬라이드).
  유닛 겹침 분리는 같은 층 + stepHeight 검증(성벽 추락 방지). 이벤트: unitFired/meleeHit/enemyDied/unitDied.
- 초기 배치: 동벽 보도 궁수 6·대포 2, 성문 다리 발리스타 2, 지상 영웅 1 — 재배치는 부대 명령으로.
- 밸런스(시드 20260725): AFK 승리, 성벽 560/2000 잔존, 93초. `siege/test/world.test.ts`가 단언.
- **영웅 스킬 「업화」 (2026-07-26)**: `heroSkill` 커맨드(지점) — 피해 500/반경 4.5/사거리 18/쿨 14초.
  자동(밀집점)/수동(레티클) 조준은 클라이언트 보조, sim은 지점만 검증 → 리플레이 포맷 불변.
- **CASTLE 상수가 단일 원천**: `{east:-6, west:-30, north:-18, south:18, wallH:11, wallT:8, gateHalf:3.2}` — 충돌·높이·렌더가 전부 이걸 공유. 렌더와 sim이 어긋나면 "봇이 검증한 판 = 플레이어가 하는 판" 보증이 깨지므로 여기서만 수정할 것.
- **2층 지형**: `heightLevels(x,z): number[]` — 성문 스트립은 `[11, 0]` (위 다리 + 아래 터널 공존). 빈 배열 = 벽체(설 수 없음). `stepHeight()`가 Δ≤1.5 연속 전이만 허용(절벽 차단). `findPath()`는 노드=셀×2+층 BFS, 클릭 면 높이가 목표 층 힌트, 목표가 벽체면 최근접 도달 지점 폴백.
- **영역 정합 (2026-07-27)**: 흉벽 띠 `PARAPET_KEEPOUT 1.3`(보도 바깥, 4면+모서리 캡+성문 다리)은 통행 불가 — 유닛이 성가퀴 돌 속에 서지 않는다. 괴수 정지선 = 벽 **바깥 면**(중심선+두께/2)+반경. 부대 대형 간격 1.8.
- 밸런스 현행(시드 20260725): 궁수 33dmg/사거리14 · 영웅 사거리13 · 야귀 660 · 갑주귀 2050 — AFK 승리, 성벽 500/2000 잔존, 90초.
- **보도는 4면 전체 개방** (모서리 연속). 내성 관통 구간(x∈[west+1.5, west+10.5], z∈[±6.5])만 차단.
- 계단: 동벽 안쪽 z∈±[4.5,15] 경사로(0→11).

### 렌더 핵심 (client/src3d/)
- Three.js 0.185: ACES 톤매핑, PBR(변위 포함), EffectComposer(SSAO+Bloom+비네트).
- **낮 씬 (2026-07-27)**: 절차 그라데이션 하늘 돔 + 태양, 오전 햇살 디렉셔널(0xfff0d2, 2.7),
  대기 원근 안개(0xc9d4e2), 노출 1.15. HDRI(dusk)는 PBR 간접광·반사용으로만 유지.
- **드로우콜 예산 (2026-08-01)**: 캐릭터는 `mergeStatic`으로 본 그룹×머티리얼 단위 병합,
  같은 배경 소품은 `InstancedMesh`, 그림자는 몸통·다리만. 새 모델을 추가할 때 이 세 규칙을
  지키지 않으면 리그 1기가 곧 프레임 예산이 된다(계측: `__siege.perf()`).
- **성능 기준 (2026-07-27)**: 개발기 GPU = Intel UHD 630 → 60fps 실측 확보. SSAO 금지(제거됨),
  변위 세분화 절제. 성능 측정은 `--use-angle=metal` GPU headless로 (swiftshader 불가).
  **동적 해상도 스케일링**(0.7~1.5, 부족 시 블룸 오프) — iGPU fill-rate 한계 대응. 1440p 전투 55fps.
- **영웅 캐릭터 창 (2026-07-27)**: LoL식 하단 카드 바 — HP·스킬 버튼·쿨다운, 카드 클릭=선택.
  다영웅 전제(sim heroSkill.heroId). 정적 석재는 병합 메시 1개(성가퀴·파라펫류).
- 30Hz sim ↔ 60fps 렌더: 이전 틱 스냅샷 + alpha 보간. 입력은 래치로 sim 스텝 안에서만 소비(드롭 방지).
- 카메라→성주 엄격 레이캐스트로 가림 벽만 페이드(성주가 성벽 위면 비활성).
- 성가퀴는 **월드 4.2 그리드** 정렬(구간·성문 이음새 간격 균일). 보도 윗면은 포장 데크 4장(벽 박스 윗면 UV 늘어짐 은폐, 본체 0.25 인하로 변위 관통 방지).
- 절차 조형 상한 검증 완료: 풀아머 기사(makeKnight)가 현재 캐릭터 퀄리티 한계선. 실사(다크소울급)는 외부 에셋 필요 — 사용자에게 고지됨.
- **타격감 (2026-08-01)**: 리그마다 **개체 전용 머티리얼**(`ownMaterials`, `userData.owned`)을 가져
  피격 플래시(150ms, 따뜻한 백색)·소멸 페이드가 그 개체에만 걸린다. 폐기는 `disposeTree`가
  전용 사본만 dispose(공유 `MATS.*` 보호). 피격 리액션 230ms(상체 젖힘+떨림+넉백)는
  **렌더 좌표에만** 더한다 — sim 좌표 불변이라 결정론에 영향 없음.
  아군 공격 모션(궁수 활 놓기/기사 내려치기/대포 포신 반동/발리스타 시위 튕김), 영웅은
  검기 투사체. 카메라 흔들림은 trauma 제곱 감쇠(대포·착탄·성벽 피격·전사·업화) — 픽셀 비용 0.
  사망은 맞은 방향으로 넘어지며 말미에만 페이드(구 스케일 축소 폐기).
- **입자 FX (2026-08-01)**: `client/src3d/particles.ts` — 연기 48·파편 96 **고정 풀**(꽉 차면
  최고령 재활용 → 전투가 길어도 프레임 예산 불변), 포스트 패스 0. 파편은 착지 시각을 미리
  계산해 그 뒤 정지(누운 조각이 미끄러지지 않게). 연결: 포연·착탄 흙먼지·성벽 석분/돌조각·
  사망 먼지·업화 검은 연기·접전 불똥.
- **톤 그레이딩 (2026-08-01)**: 기존 비네트 ShaderPass를 확장 — **패스 추가 0**(전화면 패스가
  곧 프레임 비용). ACES 톤매핑 이전(선형 HDR)에서 스플릿 톤(그림자=하늘빛 lift, 하이라이트=
  햇살 gain) → 대비(0.18 피벗) → 채도 → 비네트 순. 채택값 1.12/0.88 — 더 세게 가면 안뜰이
  푸르게 잠겨 "밤이 안 보인다" 반려 사유에 가까워진다(A/B 검증). `__siege.grade`로 라이브 조절.

## 4. 검증 방법론 (해커톤 문서용 핵심 소재)

- **sim 단독 테스트가 스크린샷보다 우선**: 이제 리포 안 `siege/test/world.test.ts` (vitest, `pnpm test`) —
  결정론·무방비 패배·기본 배치 방어 성공·부대 이동(계단 경유 하강)·지상 접전을 렌더 없이 단언.
  (구 `/tmp/pathtest2.ts` 경로 테스트는 이 테스트로 흡수/대체.)
- 시각 검증은 headless Chrome(playwright-core + swiftshader)으로 스크린샷. 단 **swiftshader는 0.5fps** —
  실시간 대기로는 sim이 안 흐른다. `window.__siege.fastForward(n, input?)` 훅으로 빨리감기 후 촬영할 것.
- 교훈 기록(로그에 원문): "성공 스크린샷은 우연일 수 있다 — sim 단언이 먼저", "본체·장식(파라펫)은 별도 레이어라 따로 점검".
