# 07. 캐릭터 시스템 v2 — 기획 확정 (2026-07-20)

상태: **결정 지점 4건 모두 사용자 확정** (아래 각 절의 ✅). 구현 착수 가능.
사용자 방향: **캐릭터는 랜덤, 고유기술 3개, 레벨이 오를수록 해금.**

## 확정 요약
- **획득**: 빌드 타임 대량 생성·검증 풀 + 클리어 시 랜덤 후보 3명 제시 → 1명 선택 영입
- **기술**: 슬롯 [패시브/자동/액티브] 고정, 해금 Lv1/Lv3/Lv5
- **성장**: Lv1~5, 경험치는 참전 클리어로만, 스탯 레벨당 +8% [초안]
- **시작 가신**: 도하(저지)/세아(딜)/단비(지원) 3인 고정, 가람/무영/하잔은 영입 풀로

## 뼈대 (사용자 방향의 구조화)

```
캐릭터 = 역할 원형(스탯 기반) × 랜덤 정체성(이름·서사·외형) × 고유기술 3종
성장   = 레벨 → 스탯 스케일 + 기술 해금 (예: Lv1 기술1 / Lv3 기술2 / Lv5 기술3)
획득   = 랜덤 (세부 방식 논의 지점 A)
검증   = 소프트 파이프라인: 생성 → 정합성 → 밸런스 봇 시뮬 → 사람 승인
```

프로젝트 논지와의 정합: 랜덤 생성이야말로 "생성이 아니라 보증"이 필요한 지점이다.
무한히 뽑히는 캐릭터 각각이 게임을 깨뜨리지 않음을 봇 시뮬이 보증해야 하며,
고유기술 조합의 밸런스 검증이 소프트 파이프라인의 핵심 시연이 된다.

## 결정 지점 (사용자 확정 필요)

### A. "랜덤"의 정확한 의미 — ✅ A2+A3 확정
| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A1 | 영입 시마다 파이프라인이 새 캐릭터를 즉석 랜덤 생성 | AI 생성 서사 최강, 무한 풀 | 런타임 생성 불가(빌드 타임 제약)라 "사전 생성 대량 풀"로 구현해야 함 |
| A2 | 사전 생성·검증된 풀(수십 명)에서 랜덤 영입 | 밸런스 통제 용이, A1과 체감 유사 | 풀 고갈 가능성(풀 크기로 해결) |
| A3 | 클리어 시 랜덤 후보 2~3명 제시 → 선택 영입 | 로그라이트 재미, 선택의 전략성 | 약간의 UI 추가 |

- 제안: **A2+A3 조합** — 빌드 타임에 대량 생성·검증한 풀에서, 클리어 시 랜덤 후보
  3명을 제시하고 1명을 선택 영입. (런타임 유료 API 금지 요건과도 정합)

### B. 고유기술 3개의 발동 방식 — ✅ B2 확정
| 안 | 내용 | 비고 |
|---|---|---|
| B1 | 전부 자동(쿨다운)/패시브 | 디펜스 조작 부담 없음. 오펜스 모드 임팩트 약함 |
| B2 | 액티브 1(수동, EX식) + 자동/패시브 2 | 오펜스 "스킬 타이밍" 조작과 직결. 성벽 액션과 조작 결이 같음 |
| B3 | 전부 수동 액티브 | 조작 과부하 (6캐릭터 × 3기술) |

- 제안: **B2** — 기술 슬롯 구성을 [패시브 / 자동 / 액티브]로 고정하면
  레벨 해금 순서(Lv1 패시브 → Lv3 자동 → Lv5 액티브)와 자연스럽게 맞물린다.
- 기술 풀 예시 (역할 원형과 조합되는 변주, 봇 검증 대상):
  패시브: 방어 관통, 저지 +1, 사거리 +0.5, 처치 시 코스트 +1 …
  자동: n회 공격마다 광역, HP 50% 미만 시 자힐, 주기적 보호막 …
  액티브: 일정 시간 공속 2배, 즉시 저지 해제+밀치기, 긴급 회복 …

### C. 레벨·경험치 구조 — ✅ 확정 (Lv1~5, 참전 경험치)
- 제안: 레벨 1~5 (해커톤 스코프), 해금 Lv1/3/5.
  경험치 = 참전한 스테이지 클리어 시 획득. 스탯은 레벨당 +8% 스케일 [초안].
- 결정 필요: 레벨업 재원을 경험치(참전)로만 할지, 재화 소모 강화도 둘지.

### D. 현 임시 로스터 6인의 처지 — ✅ D1 확정 (시작 3인: 도하/세아/단비)
| 안 | 내용 |
|---|---|
| D1 | 시작 가신 3인만 고정(튜토리얼 안정성) + 이후 전원 랜덤 영입 |
| D2 | 전원 랜덤으로 대체 (시작부터 랜덤 3인) |
| D3 | 6인 유지하되 v2 기술 체계 소급 |

- 제안: **D1** — 첫 판의 이해 가능성(심사자 30초 요건)을 고정 3인이 보장하고,
  수집 재미는 랜덤 영입이 담당. 기존 6인 중 3인(도하/세아/단비 = 저지/딜/지원)을
  시작 가신으로, 나머지는 영입 풀에 흡수.

## 검증 설계 (파이프라인 확장 — 기획 확정, 구현 대기)
- 캐릭터 밸런스 봇 시뮬: 기준 스테이지 셋(티어별 1개+)에서 "기준 로스터"의 한 자리를
  후보 캐릭터로 교체 투입 → 클리어율/성벽 잔여 변화 측정.
  - 반려 예: OP(전 지표 상승 폭 과대), USELESS(교체 시 클리어 실패 유발),
    NO_IDENTITY(기술이 원형과 사실상 동일)
- 기술 3종은 조합 폭발이 크므로, 기술 단위 사전 검증(단일 기술 on/off 시뮬) 후
  조합 검증은 표본만. [초안]

## 스코프 가드 (W3 잔여 5일 기준)
- 이 시스템은 오펜스 모드(조건부)보다 우선한다 — 수집이 게임의 정체성이므로.
- 최소 성립선: A2 풀 20명 + 기술 풀 12종(패시브4/자동4/액티브4) + 레벨 1~5.
- 폴백: 기술 3개 → 2개(패시브+액티브), 풀 20 → 12.
