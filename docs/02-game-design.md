# 02. 게임 디자인 스펙

상태 표기: [확정] 논의 완료 / [초안] 구현하며 조정 / [미결] 사용자와 논의 필요

## 컨셉 [확정]
서브컬처 캐릭터 수집 × 디펜스/오펜스 하이브리드.
- **플레이어 = 성주** (2026-07-20 확정): 끝없이 생성되는 침공으로부터 자신의 성을
  지키는 성주. 성벽 액션(수리/낙석)은 성주의 권능, 수집 캐릭터는 성주가 영입하는
  가신/용병단, 오펜스 모드는 성주의 원정.
- **디펜스**: 성벽 + 명일방주식 블로킹형 TD. 침공 웨이브를 막는다.
- **오펜스**: 블루아카이브식 분대 전진. 적이 배치한 방어선(우리 디펜스 시스템의 미러)을 수집한 캐릭터 분대로 뚫는다. 조작은 코스트 기반 스킬 타이밍.
- 코어 루프: 스테이지 돌파 → 재화/캐릭터 획득 → 전력 강화 → 다음 벽 돌파. (수집 + 스테이지 통과가 핵심 쾌감)
- 두 모드는 동일한 시뮬레이션 코어를 공유한다. 오펜스에서 "적의 배치"는 디펜스 시스템 그대로, 내 분대가 웨이브 역할.

## 성벽 지속 — 연전(캠페인) 구조 [확정 2026-07-20, 세부 수치는 초안]
- **성벽 HP는 스테이지 사이에 이월된다.** 성주의 성은 하나 — 스테이지마다 새 성벽이
  아니라, 같은 성벽으로 연속된 침공(연전)을 버틴다.
- **전투 사이 부분 회복**: 직전 스테이지에서 입은 피해의 일부를 회복하고 다음 침공을
  받는다 (회복률 [초안] — 봇 캠페인 시뮬로 데스 스파이럴 없는 최소치를 실측해 확정).
- 설계 효과: ① 봇 지표 "성벽 잔여율"이 다음 판의 시작 자원이 되어 실질적 의미 획득
  ② 스테이지 내 수리가 "다음 판을 위한 투자"로 깊어짐 ③ 파이프라인의 티어
  (EASY→NORMAL→HARD)가 캠페인 배열 순서로 자연 연결.
- 리스크 완충: 연전은 짧게(3~5판, 심사자 30초 이해 요건), 첫 판은 독립적으로도 성립.
- 구현: core는 시작 성벽 HP 파라미터(구현됨). 캠페인 루프·저장·회복률 튜닝은
  W3 메타 레이어(수집 루프)와 함께.

## 디펜스 모드 [초안]
- 그리드 맵. 타일 종류: 지상(근접 배치 가능) / 성벽 위(원거리·지원 배치 가능) / 적 진입로 / 배치 불가.
- **성벽**: 맵의 방어 대상. 성벽 HP = 라이프. 뚫린 적이 성벽을 직접 타격, HP 0이면 패배.
- **블로킹**: 지상 유닛은 블록 수(예: 1~3)만큼 적을 저지. 적은 블로커와 교전하거나(막힘) 우회 경로 탐색.
- **코스트**: 시간에 따라 자동 재생. 배치 시 소모. 철수 시 일부 환급(쿨다운 존재).
- **성벽 액션 (딱 2종만)** — **구현됨 (2026-07-20, 수치 [초안])**:
  1. 수리 — 코스트 12로 HP 180 회복, 쿨다운 8초 (배치 vs 수리 자원 딜레마)
  2. 낙석 — 쿨다운 40초 광역기, 반경 1.8타일 방어력 무시 320 피해
  - 봇 3종 모두 사용: Greedy(준비 즉시), Planner(클러스터·긴급 판단 + 여유 시 수리),
    Random(무작위). 수치는 core `DEFAULT_WALL_ACTIONS`에서 교체 가능.
  - 이 이상(성문, 출격, 업그레이드 트리)은 스코프 밖. 기획서의 확장 비전으로만 기술.
- 유닛 초기 로스터 6종: 블로커(다중 저지) / 브루저(1저지 고딜) / 원거리 딜러(아처) /
  광역 딜러(술사) / 힐러·지원(의무병) / 특수(감속사 — 감속 오라).
  **전원 구현됨 (2026-07-20, 수치 [초안])**. 근접은 자기 칸의 적을 저지 없이도 공격 가능
  (포격 정지 공성차의 근접 처치 수단).
- 적 4종: 일반(보병) / 속행(속행병) / 탱커(중장병) / 공성(공성차 — 경로 끝 2.5타일 앞
  정지 후 원거리 성벽 포격). **전원 구현됨 (2026-07-20, 수치 [초안])**.
- 배치 방향(공격 범위 방향 지정) 포함 여부: 구현 난이도 보고 결정. 1차는 방향 없는 원형/직사각 범위로 시작 가능.

## 오펜스 모드 [초안 — 3주차 조건부]
- 내 분대(수집 캐릭터 4~5인)가 경로를 따라 자동 전진하며 자동 전투.
- 플레이어 조작: 코스트 재생 → 스킬 카드 발동 타이밍 (블루아카이브 EX 스킬 방식).
- 적 측: 성벽 + 배치된 방어 유닛 (디펜스 모드의 시스템 재사용). 적 성벽 파괴 = 클리어.
- **디펜스 스테이지 검증 봇 = 오펜스 플레이 에이전트.** 같은 문제의 두 얼굴이며, 이 정렬이 기술 문서의 핵심 서사.

## 수집/성장 — 캐릭터 시스템 v2 [방향 확정 2026-07-20, 세부 기획 고도화 중]
- **[사용자 방향 확정] 캐릭터는 랜덤 생성이며, 고유기술 3개를 가지고,
  레벨이 오를수록 기술을 해금하는 형태다.** 세부 설계는 docs/07-character-system.md
  (기획 고도화 문서)에서 논의 후 확정. **코드 착수는 기획 확정 이후.**
- 이 방향은 프로젝트 논지와 정합: 캐릭터 랜덤 생성 = 소프트 파이프라인의 생성 축,
  고유기술 밸런스 = 봇 시뮬 검증 축, 승인 게이트 = 사람.
- **구현됨 (2026-07-20)**: 캠페인(연전 5판, 성벽 이월+40% 회복 [초안]) — 시작 가신
  3인(Lv1) → 클리어 시 참전자 레벨+1(기술 해금 Lv1/3/5) + 후보 3택1 영입(풀 23명) →
  localStorage 저장. 자유 연습 모드(스테이지 선택)는 별도 유지.
- 캐릭터 구성 요소: 일러스트, 프로필/서사, **고유기술 3개**, 대사(배치/스킬/승리), 레벨.

## AI 콘텐츠 공장과의 접점
- 하드 파이프라인: 스테이지(맵 지형, 배치 가능 타일, 웨이브 구성) 생성 → 봇 검증 → 출고.
- 소프트 파이프라인: 캐릭터(일러스트·스킬·서사) 생성 → 밸런스 시뮬 + 스타일 일관성 검증 → 사람 승인 게이트.
- 상세는 docs/05-pipeline.md.
