## 1. 외부 에셋 출처 — 요강 유의사항 대상

요강은 외부 에셋의 출처·라이선스를 AI 활용 기술 문서에 **반드시 명시**하도록 하고,
도용 시 **선발 취소**까지 걸어놨다. 그래서 표기를 믿지 않고 원본과 대조했다.

**발견**: 저장소 파일명은 `client/public/assets/hdr/dusk_1k.hdr`인데
문서 표기는 `kloppenheim_02_puresky`였다. 이름이 전혀 다르다.

| 확인 | 결과 |
|---|---|
| `polyhaven.com/a/kloppenheim_02_puresky` | **200** (실재) |
| `dusk`, `dusk_01`, `dusk_02` | **404** |
| Poly Haven HDRI 전체 목록에 단독 `dusk` | **없음** |
| 원본 vs 우리 파일 **MD5** | `283ef04d37153527e5407df494eaf339` **일치**, 1,393,622 bytes 동일 |

→ 표기가 정확했고 **로컬에서 파일명만 바꾼 것**이었다. 다만 다음 사람이 같은 의심을
하게 될 것이므로 `docs/asset-licenses.md`에 개명 사실과 MD5 대조 근거를 남겼다.

나머지 7종(Poly Haven 모델 3 · ambientCG 텍스처 4)도 출처 URL이 전부 200으로 실재 확인.
