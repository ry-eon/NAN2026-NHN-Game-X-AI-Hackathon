**발견**: 저장소 파일명은 `client/public/assets/hdr/dusk_1k.hdr`인데
문서 표기는 `kloppenheim_02_puresky`였다. 이름이 전혀 다르다.

|---|---|
| `polyhaven.com/a/kloppenheim_02_puresky` | **200** (실재) |
| `dusk`, `dusk_01`, `dusk_02` | **404** |
| Poly Haven HDRI 전체 목록에 단독 `dusk` | **없음** |

## 6. 긴급 — 하단 HUD가 화면 밖으로 잘림 (영상 촬영 중 발견)

사용자: *"영상 찍다가 알게된건데 이거 어어어 아래가 짤린다 전군, 영웅 아래"*

**측정으로 원인 확정** (추측 금지 원칙 적용, 브라우저에서 실제 박스 측정):

| 요소 | 실측 | 판정 |
|---|---|---|
| `#bottombar` | `height:178px` **고정**, 내부 154px | — |
| 좌측 열(미니맵+버튼 4개) | **209px** | 55px 초과 |
| `align-self:center` | 위 15px · **아래 15px 화면 밖** | `자동 장착 B`·`총 백병전 V` 행이 잘림 |
| 영웅 카드 105px · 커맨드 카드 112px | 154 이내 | 정상 |

즉 **잘린 건 영웅 카드가 아니라 좌측 버튼 행**이었다.

### 조치 — "HUD는 절대 잘리지 않는다"를 구조로 보장

1. **버튼 4개를 미니맵 아래 → 옆으로.** 열 높이 209 → **151px** (154 이내).
   바를 키우면 3D 화면이 55px 깎이는데, 촬영 중이라 화면을 지키는 쪽을 택했다.
2. `height:178px` → **`min-height:178px`.** 내용이 커지면 잘리는 대신 바가 자란다.
3. 1번이 좌측 열을 100px 넓혀 **가로 회귀**가 생겼다 — 1152px 이하에서 커맨드 카드가
   화면 밖으로 밀렸다. 원인은 영웅 카드 3장(600px)이 min-content라 줄지 못하는 것.
   → `flex-wrap:wrap` 추가. 밀려나는 대신 아랫줄로 간다.

### 검증 — 폭 스윕 (영웅 카드 3장 실측 치수 600×105 대입)

| 창 폭 | 2560~1280 | 1152 | 1024 | 900 | 800 |
|---|---|---|---|---|---|
| 바 높이 | 178 (변화 없음) | 284 | 440 | 389 | 389 |
| 잘린 요소 | **0** | **0** | **0** | **0** | **0** |

1280px 이상은 기존과 동일하고, 그 아래는 **숨는 대신 바가 자란다**(이전에는 그냥 잘렸다).
빌드·타입체크 통과, 테스트 106개 통과.

**교훈**: 고정 height는 내용 크기를 추적하지 않는다. HUD처럼 내용이 계속 늘어나는 곳
(영웅 2 → 3, 버튼 2 → 4로 늘어왔다)에는 `min-height` + `wrap`이 맞다.

## 7. 플레이 영상 촬영·편집·게재

사용자가 직접 조작해 촬영(요강 §2 대응 — 시연 봇 미사용). 원본 117.97초 · 1902×936 · 60fps · **무음**.

### 원본 분석 (프레임 추출로 시간축 확인)

| 초 | 사건 |
|---|---|
| 0~12 | 준비. 미장착 링이 8개 → 6 → 4 → 2 → **0**(12~14초 장착 완료) |
| 8 / 28 / 56 / 60 | 웨이브 1 / 2 / 3 / **4(마지막 물결, 괴수 최대 24)** |
| 88→92 | 괴수 **5 → 7로 증가** = 네크로맨서가 되살림 |
| ~102 | 전사 사망 (HP 550→280→140→50, 12초에 걸쳐 무너짐) |
| 112 | 승리 「성을 지켜냈다」 (성벽 1424/2000) |

### 편집 — 두 번 잘랐고 한 번 틀렸다

요강이 30~60초이므로 118초는 자를 수밖에 없다. 1차 컷을 `0~8초 + 62~114초`로 만들었는데
사용자 반려: *"장착도 전에 바로 네크로로 넘어가는데?? 제대로 편집 한거 맞아..?"*

**원인**: 8초는 미장착 링이 **아직 6개 남은 시점**이었다. "장착을 보여주겠다"고 자르면서
정작 장착이 완료되는 장면(12~14초)을 잘라버렸다. 링 개수를 프레임에서 세어 확인 후 재편집.

**최종(B)**: `0~17초`(미장착 → 이동 → 링 소멸 → 배치 완료 → 첫 교전) + `71~114초`
(웨이브 4/4 최대 교전 → 네크로맨서 → 전사 사망 → 승리). 이음매에 0.4초 암전 —
툭 끊기면 오류로 보이고, 페이드가 있으면 의도한 편집으로 읽힌다.

### AI 조작·합성 여부 (요강 §2)

프레임 생성·보간·업스케일·색보정·속도 변경 **일절 없음**. 잘라내고 이어붙인 것이 전부이며
남은 프레임은 원본 그대로다. 해상도 1902×936 · 60fps 원본 유지(ffprobe 확인).
