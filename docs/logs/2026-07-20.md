## 결정 사항
- **Random 봇**: 1초마다 50% 확률로 무작위 유닛·무작위 유효 타일 배치. core 시드 RNG만
  사용 — 같은 시드 = 같은 플레이 (평가 재현성).
- **Planner 봇**: 킬존 계획(원거리 커버리지 최대 진입로 셀 = 초크포인트), 최적 블로커
  대기(코스트 저축 — Greedy와 갈라지는 지점), 저지/DPS 부족 판단 배치, 누수 긴급 대응.
  상수(DPS 지평 12s 등)는 전부 [초안].
- **evaluateBots**: 봇×N회 → 클리어율, 평균 성벽 잔여율, 평균 클리어 시간 집계.
  판정 임계값은 넣지 않음 — 난이도 지표 확정은 [미결]이므로 사용자 논의 후.

  코스트 구조라 아무렇게나 놓아도 막힌다.

## 추가 세션 (같은 날): stage-002 "갈라진 진격로" — 등급 변별력 확보
- 지시: "1번 스테이지 002부터 진행해줘"
- 설계: 이중 레인(A 꺾임/B 직선) + 성벽 위 배치 3칸 제한 + 타이트 경제(초기 10, 0.8/s)
- **밸런싱 8회 반복** (전 과정 프로브 계측 기반, 기술 문서용 핵심 서사):
  1. 초판: 전 등급 100% 클리어 — 압박 부족
  2. Planner가 레인 B를 53s까지 방치 → 저지 부족 판정을 전역→경로별로 수정
  3. Greedy가 아처 6기 도배로 무손상 클리어 발견 → 성벽 위 3칸 제한 (맵 수정)
  4. 동시 페어 투입 → Planner 저축 규칙이 아처 구매를 고사시켜 전패 →
     "제때 모을 수 있을 때만 저축" + 부족 판정에 ETA 10s 창 도입
  5. 여전히 Planner 전패: 성벽 캠핑 적을 원거리 없이 못 죽임 →
     오프너(원거리 0기면 최우선)·캠퍼 청소 규칙 추가
  6. 오프너가 커버 얇은 레인을 놓침 → "최약 레인 커버 최대화" 균형 오프너로 교체
  7. 적 스탯 상향(보병 480/속행 190/중장 1250) — 아처 3방 컷이 원거리 스팸의 근원
     → W1은 완만하게 되돌려 난이도 램프 형성
  8. 조합은 갈렸지만 Planner의 레인 B 근접이 0.8s 늦어 4클럼프 누수 →
     **스폰 테이블 사전 계획(predictClumps)**: 동시 도착 무리를 예측해 도착 전에
     해당 레인 저지 capacity 확보. Planner의 정의("계획")를 실제로 구현한 조각.
- **최종 실측 (봇별 10회)**: Planner 클리어 100%·성벽 잔여 55% / Greedy 100%·30% /
  Random 10%·1% — 3단 분리 달성, 테스트로 고정 (bots/test/stage-002.test.ts)
- client: 스테이지 선택 버튼 + 맵 크기 가변 타일. 헤드리스 스크린샷으로 확인.
- 배운 것: 봇 등급이 맵 설계 결함(아처 스팸 지배 전략)을 자동으로 찾아낸다 —
  "봇 = 스테이지 검증기" 논지가 밸런싱 도구로도 성립함을 확인.
