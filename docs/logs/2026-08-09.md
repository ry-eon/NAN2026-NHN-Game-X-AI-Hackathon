# 2026-08-09 — 캐릭터 디자인 분화 (D-1)

## 반려 — "캐릭터 디자인은 못 바꾸는 거야? 갑옷은 동일하게 입고 있네"

8/8의 직군 소품(검·지팡이·지휘봉)은 색 스왑 + 손 소품이었고, 몸체가 전부 같은
판금 기사라는 지적. 실루엣 자체를 갈랐다:

- **마법사 = `makeMage` 별도 조형** (기사 몸체 재사용 아님): 판금 0 — 통짜 로브
  (어깨→밑단 한 프로파일) + 후드(얼굴은 어둠 — 기사의 '얼굴 없음' 문법 공유) +
  넓은 소매·검은 손 + 앞자락 패널·금 노끈·화염 문장 + 화염 구슬 지팡이(발광).
  Rig 계약(팔다리 피벗)은 동일해 기존 보행/공격 애니메이션을 그대로 탄다.
- **성주 = 예장(regalia) 옵션**: 크레스트·서클릿 제거 → **왕관**(금륜+뾰족 5),
  어깨 맨틀(검은 깃+금 테), 케이프 0.55×1.05 → 0.78×1.35 확장. 흑색 갑주+지휘봉 유지.
- 전사는 판금 기사 유지(뽑아 든 검) — 근접 직군이라 갑주가 정체성.

본 그룹 병합 규칙 유지(드로우콜 불변). 빌드·화면 확인: 마법사 진홍 로브 실루엣 분리 확인.

## 2차 — 성주 귀족 예복 + 계단 합류 띠 잠김

- **성주 = `makeLord` 별도 조형** ("귀족 복장, 갑옷 없는 버전"): 판금 0 — 더블릿(금단추
  4·벨트 버클)·천 바지·무릎 가죽 부츠·하이칼라·가죽 장갑·어깨 맨틀(금 테)·왕관·확장
  케이프·지휘봉. 머리는 어둠 + 왕관 — 투구 없이도 '얼굴 없음' 문법 유지.
  전장의 유일한 비무장 실루엣 = 지휘관. (8/9 1차의 regalia 기사는 폐기)
- **계단→보도 합류 띠 잠김 수정**: 렌더 계단은 x=−10에서 끝나는데 sim 경사 밴드는
  −9.8까지라, 꼭대기 합류 순간(x −10~−9.8, h 9.5~11) 모델이 보도 몸체 옆면 속을
  걸었다("성벽 안쪽으로 하체가 들어간다"). 합류 띠에서 h가 꼭대기 부근이면 보도
  윗면(11)으로 스냅 — 낮은 h는 제외해 저지대 오탐 방지.

## 3차 — "스킬 이펙트가 다 같다" → 9종 전면 분화

3계열 형태 언어로 재설계 (신규 헬퍼: spawnSkillRing pulse/boundary · spawnSlashArc · spawnDashTrail):
- **전사 = 강철빛 궤적**: Q 돌진(출발→도착 잔상 리본, 직전 틱 위치가 출발점) ·
  W 회전베기(둘레를 도는 검기 호) · E 대지파쇄(이중 충격파+모래빛 링+석분)
- **마법사 = 화염 3단**: Q 화염구(팝 — 기둥·충격파 없음, 속사감) · W 불의 장막(깔린 불 +
  **경계 링이 지속시간 내내**) · E 업화(대형 기둥+충격파 — 현행 유지, 궁극의 무게)
- **성주 = 영역 링**: Q 군기(금)/W 나팔(청록) — 확장 펄스 + **실제 반경 12의 지속 링**
  ("범위가 안 보이면 버프가 없는 것과 같다") · E 총력전(삼중 금 링 + 뿔피리)
- SFX 4종 신규 합성(fireball·firewall·dash·rally — 총 18종, 여전히 오디오 파일 0개)
- sim: skillCast 이벤트에 casterId 추가(돌진 출발점·시전자 높이 참조용)

테스트 106개·빌드 통과.

## 4차 — "스킬이 전 영역이 아니라 시전되는 곳이 정해져 있는 것 같다"

정체는 시전 사거리(마법사 16~18·돌진 14) 밖 클릭을 sim이 조용히 무시하던 것.
사거리 자체는 유지 — 마법사의 서는 자리가 곧 개입이라는 축(봇 검증 "개입 보상")을
지키기 위해서다. 대신 UX를 LoL 관례로:
- **조준 중 시전자 둘레에 사거리 원**(rangeRing — 시전자가 걷는 중이면 따라간다)
- **사거리 밖 클릭 = 최대 사거리 지점으로 클램프 시전** — 무시가 아니라 반드시 나간다.
  레티클도 클램프된 실제 낙하점을 보여준다. sim 검증 불변(클라이언트가 유효 지점만 보냄)
