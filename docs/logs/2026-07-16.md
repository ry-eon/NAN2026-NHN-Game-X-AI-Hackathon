## 반려·재시도 기록
- **Phaser 4 → 3 교체**: `pnpm add phaser`가 v4.2.1을 설치. 기술 스택은 Phaser 3로 [확정]이므로
  에이전트가 임의 업그레이드하지 않고 v3.90.0으로 재설치. (v4 채택 여부는 필요해지면 별도 논의)
- **TypeScript 7 호환**: tsconfig의 `baseUrl`이 TS7에서 제거됨 → `paths`를 상대 경로로 수정해 해결.
- **@types/node 누락**: vite.config.ts가 `process`/`node:url` 참조 → devDependency 추가.

## 결정 사항
- **단일 패키지 + 폴더 분리** (pnpm workspace 아님): 1인 개발에 workspace 오버헤드 불필요.
  core 순수성은 (1) core의 zero-dependency, (2) client→core 단방향 `@core` alias로 지킨다.
  W2 파이프라인 착수 시 자동 가드(core에서 phaser import 금지 lint) 추가 검토.
- **base 경로 동적 주입**: Pages는 `/<repo>/` 하위 서빙. 빌드 시 `GHPAGES_BASE` env로 주입하고
  CI에서 `github.event.repository.name`으로 채움 → 리포 이름이 바뀌어도(게임 제목 미정) 안전.
- **placeholder 씬이 core의 `CORE_VERSION`을 표시**: 게임 로직 없이 client→core 의존 방향만 검증.
- 리포 이름 잠정 `nan2026` (게임 제목 [미결]이므로 중립 이름, base 동적 주입 덕에 개명 자유).
