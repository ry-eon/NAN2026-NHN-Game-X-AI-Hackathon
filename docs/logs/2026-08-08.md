## 디렉션 — 장착제 (사용자 확정)

> "시작하면 미리 준비된 게 아니라 성벽 안에 정리되어 있고, 대포와 발리스타에
> 장착하는 형식. 장착하면 쏘고 아니면 분리."

무개입 승리 전제(V0)와 충돌함을 보고하자:

> "우선 아무것도 안 하면 지는 게 맞지 않나? 그냥 이기면 게임의 의미가 없는 거 같아."

V0의 무개입 승리가 테스트 편의였는지 확인 요청 → 기록 확인 결과 **의도된 설계**였음
(verify.ts 주석: "기본 배치가 성립한다는 뜻" + 여유 상한 1400으로 "너무 쉬움"도 반려).
그러나 §4-4에 "기준을 바꾸는 것도 기획 결정"이라 명시돼 있었고, 사용자가 철학을 전환:
**"결국 배치와 영웅 사용이 주가 되는 게 맞는 것 같아"** → 개정 확정.

## 구현 — sim·봇·클라이언트·검증

- **sim**: 수비병 안뜰 2열 종대 집결(병기 수만큼), `crewOf` 고정 짝 폐지 →
  `manningMap` 동적 배정(병기 id 순 최근접, 1병사 1병기 — 두 포좌 사이 꼼수 차단).
  조작 위치 `mountPoint` 2.0(사용자 지적 반영: 1.5 → 2.0). **새 커맨드 없음 = 리플레이 포맷 불변.**
- **봇 4등급**: `deploy`(표준 장착 후 무개입) 신설 — 구 무개입 기준선 계승.
  greedy·random도 장착 후 행동. afk는 정말 아무것도 안 함 → **패배해야 통과**.
- **CRITERIA_V1**: 무개입 패배 / 표준 장착 승리 150~1400 / 개입 보상 / 무작위 생존 / 45~150초.
- **클라이언트**: 장식 조작병 제거(발사 연출은 본체 반동 유지), 병기 우클릭 = 조작 위치
  스냅 이동(pickWeapon), G = manningMap 기준 토글, 준비 단계 HUD "병기 N기 미장착!" 안내.

## 실측이 만든 규칙 — 행군 관통 (봇 검증이 두 번 잡아냈다)

1. **경사로 군중 잼**: 집결 수비병들이 폭 2.6 경사로에 동시에 몰리면 겹침 분리가 서로
   밀어내 영원히 못 오른다 — 6기가 입구에서 100초+ 공회전, 판이 prep에서 안 끝남.
2. **포좌 곁 무한 제자리걸음**: 경로 격자가 대포 곁 1.0을 지나는데 분리가 1.45로 밀어내
   웨이포인트 도달 판정(0.14)을 영원히 못 넘긴다.

→ **분리는 정지한 유닛 사이에서만** (이동 중엔 관통 — RTS 관례). 이 규칙 없이는
플레이어의 "전 수비병 선택 → 성벽 우클릭"도 같은 잼에 빠진다.

## 2차 피드백 — "장착됐는지 UI로 확인이 안 된다"

> "주변에 가긴 하는데 대포가 날아가는 거(발사) 말고도 추가로 뭔가가 필요할 듯"

정확한 지적: 준비 단계엔 적이 없어 발사라는 확인 수단 자체가 없다. 렌더 전용 피드백 3종 추가:

1. **미장착 링** — 조작 필요 병기 바닥에 흰 점멸 링. 장착되면 사라진다.
   준비 단계 배치 확인 + 전투 중 수비병 이탈 경보를 겸한다.
2. **장착 성사 펄스** — 장착 순간 병기 위치에 금색 확장 링 + 걸쇠음(`mount` SFX 신규,
   WebAudio 합성 14종째 — 이 게임에서 상승하는 소리는 부활과 장착뿐).
3. **장착 스냅 마커 금색** — 병기 우클릭 시 이동 마커를 금색·1.8배로 — "이동"이 아니라
   "장착하러 간다"로 읽히게. (일반 이동=녹, 조준=주황, 어택땅=적, 장착=금)

sim 무변경(렌더 계층만). 링 머티리얼은 개체 전용 owned 마킹 — 재시작 시 disposeTree 회수.
